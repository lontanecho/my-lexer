# my-lexer

C++17 编写的 C/C++ 风格教学词法分析器。读取一个源文件，输出记号类型、起始行列和原始词素，以及统计结果和全部可检测的词法诊断。

## 构建与运行

```powershell
cmake -S . -B build
cmake --build build
.\build\my-lexer.exe .\src.txt
ctest --test-dir build --output-on-failure
```

回归测试需要 Python 3；CMake 检测到 Python 后会注册测试。也可直接运行：

```powershell
python tests/test_lexer.py build/my-lexer.exe
```

记号表及统计写入标准输出，词法诊断写入标准错误。有词法错误时退出码为 1，但仍扫描完整个文件并输出 EOF；无错误时为 0。

## 识别范围

- 关键字以 `src/data_structure/keyword_table.cpp` 中的表为准。
- 标识符：ASCII 字母或下划线开头，后续允许字母、数字、下划线。
- 十进制整数与浮点数，支持 `.5`、`1.`、`1.2e-3`、`2E+4`。
- 单字符常量和字符串；支持简单转义 `\\`、`\'`、`\"`、`\?`、`\a`、`\b`、`\f`、`\n`、`\r`、`\t`、`\v`、`\0`。
- 现有 token 表中的运算符和界符，优先匹配最长运算符。
- `//` 行注释与 `/* ... */` 块注释；注释不产生记号，字符串内部的注释符不视作注释。
- 行首（允许前导空白或注释）的预处理指令，允许 `# define` 等写法。只识别指令词和后续普通记号，不执行宏展开或包含文件。

这是教学子集，不是完整的 C/C++ 标准词法实现：不支持非十进制数字、数字后缀、原始/宽字符串、Unicode 标识符或反斜杠续行；输入按无 BOM 文件处理。尖括号形式的 include 参数按现有普通记号拆分，不提供独立头文件名记号。

## 统计口径

- 源程序行数：物理行数，包含空行和注释行。空文件为 0 行，末尾换行不额外产生空行；CRLF 算一次换行，同时支持 LF、CR。
- 代码行数：至少含一个成功识别的记号的行数；不是语法层面的语句条数。
- 字符总数：原文件字节数，包含空白、换行、注释和错误内容。ASCII 字符每个计 1，UTF-8 中文按其编码字节数计；CRLF 计 2 字节。
- 分别统计关键字、标识符、整数、浮点数、字符、字符串、运算符、界符、预处理指令的出现次数。不是去重计数。错误词素、注释和 EOF 不计入有效单词总数。
- 注释个数包含未闭合块注释。错误数按实际诊断条数计，同一字符串的多个非法转义可分别报告。
- 行、列均从 1 开始；列按字节计数，制表符计 1 列。

## 错误恢复与一次扫描

扫描器只向前移动索引，在消耗字符时同步更新位置和统计，不再先遍历源文件建立位置表。

| 错误 | 报告位置 | 恢复方式 |
| --- | --- | --- |
| 非法字符（包括源文件中的空字节） | 字符位置 | 跳过该字节继续 |
| 非法数字，如 `123abc`、`1e+`、`1.2.3` | 词素起点 | 消耗错误数字词素，保留其后的运算符/界符 |
| 空或多字符的字符常量 | 开引号 | 扫描至闭引号或行尾继续 |
| 非法转义 | 反斜杠 | 记录后继续检查同一常量，仍可报告后续非法转义 |
| 字符/字符串未闭合 | 开引号 | 在行尾或文件尾结束该错误词素 |
| 未知预处理指令 | `#` | 消耗指令名称，继续处理后续词素 |
| 块注释未闭合 | `/*` | 消耗至文件尾并报告；其内部按注释处理 |

“所有词法错误”指上述词法规则及恢复策略能够检测到的错误；类型不匹配、变量未声明、括号配对等属于后续语法或语义分析，不在本程序检查范围内。
